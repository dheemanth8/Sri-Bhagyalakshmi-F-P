# Sri Bhagyalakshmi Fertilizers & Pesticides
### శ్రీ భాగ్యలక్ష్మి ఫర్టిలైజర్స్ & పెస్టిసైడ్స్ (Estd. 1995)

> A production-grade, bilingual (English & Telugu), high-performance responsive web application for **Sri Bhagyalakshmi Fertilizers & Pesticides**, an agricultural retail business established in 1995 in Allagadda, Andhra Pradesh.

## 🌟 Features

- **Bilingual Experience:** Seamless switching between English and Telugu (`EN | తెలుగు`), with preference persisted in `localStorage`.
- **24 Official Brand Logos:** Bayer, Tata Chemicals, FMC, Corteva, ADAMA, Nova AgriTech, Prism, BASF, Indofil, NACL, Garudha, Nichino, IAL, Coromandel International, GSP, Tropical Agrosystem, SPIC, NFL, FACT, KRIBHCO, IFFCO, Mahadhan, PPL, and IPL with original local brand logos.
- **Agricultural Product Categories:** 6 image-based categories (Organic Production, Fertilizers, Crop Protection, Insecticides, Fungicides, Herbicides) with direct enquiry triggers.
- **High-Performance Loading:** Modern WebP responsive image formats, LCP hero image prioritization, lazy loading, and non-blocking font rendering.
- **Integrated Google Maps & GPS:** Verified store coordinates with interactive map and directions.
- **Centralized Business Configuration:** Single source of truth in `src/data/business.ts` for store details, address, hours, and contact configuration.

## 🚀 Getting Started

```powershell
# Install dependencies
npm install

# Start local development server
npm run dev

# Create production build
npm run build

# Preview production build locally
npm run preview

# Run linter
npm run lint

# Optimize images
npm run optimize-images
```
